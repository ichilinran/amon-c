# 凍結SDKのソース配布確認

2026-11-01。完全SDK1,991本文、初期SDK108本文を対象とします。対象はJSON/gzipへ格納したヘッダのソース本文です。ホストのライブラリ本体をWasmへリンクしたとの判定ではありません。

## ファイルごとの確認

[sdk-file-terms-review.json](sdk-file-terms-review.json)に全本文のSHA-256、個別条件・SPDX表現、出所資料、確認根拠を記録しました。個別の原文を優先し、同じパッケージという理由だけで異なる条件を一律に上書きしません。SPDXのOR/AND/例外と、独自の許諾文を保持しています。

短い生成・転送用ヘッダでは個別のライセンス宣言がないものがあります。glibcの短いヘッダ58件、Linuxの生成・転送用等34件、dialog/Expatの生成設定各1件等は、出所パッケージやLinux COPYINGの適用範囲を根拠として明記しました。これはファイル内に存在しないSPDXを作ったという意味ではありません。glibcの対象477件は以前に公式配布パッケージともバイト一致を確認済みです。

## 今回補った内容

- JFFS2のヘッダが直接参照する `fs/jffs2/LICENCE` を取得・保持しました。GPLの版指定と特別な例外を、一般的なLinuxのsyscall例外で置き換えません。
- CodaのヘッダはGNU Library General Public Licence Version 2とCMU独自条件の選択肢をそのまま保持します。CMUの著作権・許諾・クレジット記載も補足資料に収録しています。
- SGI/Hewlett-PackardのSTL由来部分、Pillow等にある「付属資料にも表示を置く」条件に対応するため、SDK内の表示を [SDK-HEADER-NOTICES.txt](../LICENSES/SDK-HEADER-NOTICES.txt) に取り出しました。1,204件の重複しない表示ブロックを、元のパスとともに収録しています。
- rpcsvc-protoの12件は、対応するv1.4.2の `.x` 入力からrpcgen 1.4.2で再生成し、全件で本文がバイト一致しました。入力・出所・ハッシュ・OracleのBSD-3-clause表示との対応を保持しています。
- GCCのCOPYING3、curlのCOPYING、LinuxのCOPYINGも出所を明記して補いました。既存のGPL/LGPL・Linux・GCC例外本文も継続して保持しています。

## この配布での扱い

全本文と元の表示を配布し、復元スクリプト・条件本文・出所対応・補足表示へ同じ配信物から到達できる構成です。第三者のソースをMITに再指定せず、改変していないホスト1,964本文をそのまま保持します。Clang由来8本文の既存変更には注記と差分があります。

この凍結SDKについて、ソース本文の配布に必要な表示・参照本文・回復経路の確認を済ませたと判断します。法的な保証書ではなく、将来のSDKやホストライブラリのリンク配布まで許諾確認したとの意味でもありません。SDKが変わる場合はハッシュ検査が失敗するため、適用範囲と条件を再確認します。

確認コマンドは `python3 tools/check-sdk-source-review.py --rpcgen` と `npm run check:distribution`。後者は出所や表示の整合検査で、未解決のWasm条件や公開前の全体検証を自動的に承認しません。
